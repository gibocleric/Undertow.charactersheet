# Undertow Character Builder

## Publish with GitHub Pages

Upload `index.html`, `community-trees.json`, `site-config.json`, and the `assets` and `fonts` folders to the repository folder selected in **Settings → Pages**. Keep the folders beside `index.html`; the app uses relative paths for its images and fonts.

After the upload, wait for the Pages deployment to finish. Open the published site URL to use the character builder. Characters are saved in the current browser and can be transferred with the app's Export and Import character file buttons.
