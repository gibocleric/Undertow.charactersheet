# Undertow Character Builder

## Publish with GitHub Pages

1. Create or open a GitHub repository.
2. Upload **everything in this folder** to the repository root. Keep `index.html`, `fonts/`, `assets/`, and the included root-level images in their current relative locations.
3. Commit the uploaded files to the `main` branch.
4. In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to finish deploying, then open the URL shown in that Pages section.

Do not upload only `index.html`: it needs the included fonts, images, and `assets/` folder to display correctly.

Custom perks are added from the **Custom** perk tree. Saved characters stay in the player's current browser on that device; they are not shared between browsers or devices.
